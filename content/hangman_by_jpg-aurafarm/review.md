# Ревью проекта [hangman](https://github.com/jpg-aurafarm/hangman)


## Плюсы

- Хорошая декомпозиция. 
Логика игры, состояние сессии/меню, ввод-вывод через абстракцию и оркестрация разделены. 
Это намного лучше чем всё в одном файле как обычно пишут этот проект строк на сто.

- Чистая модель игры. `letters_state` с флагами `in_word/called/indices` - простая и наглядная структура. 
Отдельные методы `check_guess/get_masked_word/is_won/is_lost` понятны.

- Есть Валидация ввода. Проверка длины (ровно 1 символ), проверка на кириллицу по `ALPHABET_RU`, обработка уже названной буквы.

- Удобный UI/UX в мелочах:, меню, показ уже названных букв, счётчик ошибок.

- Гибкий режим игры. Меню с "играть пока не надоест" (`MARATHON`) / "сыграть один раунд" (`SINGLE`), корректный выход.

- Надёжная загрузка слов. 
`words_loader.load_words` с fallback на `DEFAULT_WORDS` при отсутствии файла или пустом файле `words.txt`.


## Минусы

- Дублирование сообщения о проигрыше. 
В `render_game()` при `lost` выводится `TEXTS["lose"]`, а после перехода в `GAME_OVER` `run_game_over_step()` снова вызывает `render_game()`. 
Таким обращом в консоль сообщение дублируется.

- Нет явного фидбека при правильном ответе. 
При угадывании новой буквы `run_play_step()` пользователь не видит отдельного сообщения "Верно! Буква есть в слове." 
(есть только константа `GuessStatus.RIGHT` в `game.py`, но она нигде не выводится).

- Лишние странные элементы в константах. 
`HANGMAN_ART` импортируется в `session.py`, но не используется там. 
В `TEXTS` есть `called_input` и `called_chars` один и тот же смысл них. 
`GameStepResult` дублирует информацию о статусе (некоторые значения не используются). 
`MenuChoiceResult` частично дублирует `GameMode`.

- Небольшие стилистические шероховатости. 
Отсутствуют пробелы после запятых в некоторых импортах, длинные строки, смешанные стили. Присутствуют не используемые импорты


## Итог

Крепкая, продуманная реализация с хорошей архитектурой. Логика игры корректная.
Основные замечаний - UI-детали (дубль сообщения о проигрыше, отсутствие фидбека при верной букве). 
Архитектурно решение выше среднего.
